ATIVIDADES - TREINAMENTO GIT E GITHUB


1 - CRIAR UM PROJETO NO COMPUTADOR

    Crie uma pasta no seu computador chamada "aulagit1".
    Dentro da pasta, crie um arquivo chamado "aula.js".
    Adicione o seguinte código:
    console.log("Aula de Git");
    Abra o GitHub Desktop e adicione a pasta como um novo repositório.
    Faça o commit das alterações e publique o repositório no GitHub.


2 - CRIAR UM REPOSITÓRIO PELO GITHUB

    Acesse o GitHub e crie um novo repositório chamado "aulagit2".
    Faça o clone desse repositório para o seu computador utilizando o GitHub Desktop.
    Dentro da pasta do projeto, crie um arquivo chamado "comparacao.js".
    Crie um código utilizando IF que verifique se o número 2 é maior que o número 1.
    Exemplo:

    if (2 > 1) {
        console.log("2 é maior que 1");
    }

    Faça o commit e envie a alteração para o GitHub.


3 - CRIAR, ENVIAR, APAGAR E RECUPERAR

    Crie uma pasta no computador chamada "aulagit3".
    Dentro dela, crie um arquivo chamado "mensagem.js".
    Adicione o seguinte código:
    console.log("Meu primeiro projeto no GitHub");
    Crie um repositório no GitHub utilizando essa pasta pelo GitHub Desktop.
    Faça o commit e envie o projeto para o GitHub.
    Depois de confirmar que o projeto está no GitHub:

    1. Apague completamente a pasta "aulagit3" do computador.
    2. Tire um print mostrando que a pasta foi apagada.
    3. Faça o clone do repositório novamente pelo GitHub Desktop.
    4. Coloque o print dentro da pasta do projeto.
    5. Faça um novo commit.
    6. Envie a alteração para o GitHub.


4 - CRIAR UM REPOSITÓRIO PELO GITHUB E EDITAR UM ARQUIVO

    Acesse o GitHub e crie um novo repositório chamado "aulagit4".
    Faça o clone do repositório utilizando o GitHub Desktop.
    Crie um arquivo chamado "frase.js".

    Adicione:
    console.log("Estou aprendendo Git");
    Faça o commit e envie o arquivo para o GitHub.
    Depois disso, altere o código para:
    console.log("Estou aprendendo Git e GitHub");
    Faça um novo commit e envie novamente para o GitHub.
    Ao final, o arquivo deverá conter a segunda mensagem.


5 - CRIAR UM PROJETO NO COMPUTADOR E ADICIONAR UM NOVO ARQUIVO

    Crie uma pasta no computador chamada "aulagit5".
    Dentro da pasta, crie um arquivo chamado "inicio.js".
    
    Adicione:
    console.log("Primeiro arquivo");
    Crie um repositório utilizando o GitHub Desktop.
    Faça o commit e envie o projeto para o GitHub.
    Depois disso, crie um segundo arquivo chamado "segundo.js".

    Adicione:
    console.log("Segundo arquivo");
    Faça um novo commit e envie a alteração para o GitHub.
    Ao final, o repositório deverá possuir os dois arquivos.


6 - CRIAR UM PROJETO NO GITHUB E FAZER DUAS ALTERAÇÕES

    Crie um novo repositório no GitHub chamado "aulagit6".
    Faça o clone utilizando o GitHub Desktop.
    Crie um arquivo chamado "atividade.js".

    Adicione:
    var numero = 10;
    console.log(numero);
    Faça o commit e envie para o GitHub.
    Depois altere o arquivo para:
    var numero = 20;
    console.log(numero);
    Faça um novo commit e envie novamente para o GitHub.
    Depois crie um segundo arquivo chamado "resultado.js".

    Adicione:
    console.log("Atividade concluída");
    Faça um novo commit e envie para o GitHub.
    Ao final, o projeto deverá possuir dois arquivos e três commits.


7 - CRIAR UM PROJETO NO COMPUTADOR E FAZER DOIS COMMITS

    Crie uma pasta no computador chamada "aulagit7".
    Dentro dela, crie um arquivo chamado "aluno.js".

    Adicione:
    var nome = "Seu Nome";
    console.log(nome);
    Crie o repositório utilizando o GitHub Desktop.
    Faça o primeiro commit e envie para o GitHub.
    Depois altere o código para:
    var nome = "Seu Nome";
    var idade = 20;
    console.log(nome);
    console.log(idade);
    Faça um segundo commit e envie novamente para o GitHub.
    Ao final, o histórico do GitHub deverá apresentar pelo menos dois commits.


8 - CRIAR UM REPOSITÓRIO NO GITHUB E RECUPERAR O PROJETO

    Crie um novo repositório no GitHub chamado "aulagit8".
    Faça o clone utilizando o GitHub Desktop.
    Dentro do projeto, crie um arquivo chamado "computador.js".

    Adicione:
    console.log("Projeto criado no computador");
    Faça o commit e envie para o GitHub.

    Depois:
    1. Apague a pasta do projeto do computador.
    2. Tire um print mostrando que a pasta foi apagada.
    3. Faça novamente o clone do repositório pelo GitHub Desktop.
    4. Dentro do projeto recuperado, crie um arquivo chamado "recuperado.js".
    5. Adicione:

    console.log("Projeto recuperado do GitHub");

    6. Faça o commit.
    7. Envie a alteração para o GitHub.

    Ao final, o repositório deverá possuir os arquivos "computador.js" e "recuperado.js".
